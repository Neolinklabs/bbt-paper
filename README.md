## 编写约定

正文使用 Markdown 编写，原始材料单独保留。后续修改白皮书工作稿时，在迭代记录中说明重要变化；新增素材记录来源和日期。

原稿中的名称为“百博（Babel）”，本仓库按用户指定使用“Babel Town”作为项目名称，原文暂保留原称呼。两者的品牌关系留待后续统一。

## 当前进度

已于 2026 年 11 月 1 日导入首份白皮书，并按补充方向形成首批节点方案和统计口径 v0.1。百万在线覆盖供给、消费和供需一体，当前优先组织机构资源；世纪互联采购方向已由用户明确，具体卡数、交付批次和其他参与方待补充。

节点方案、统计口径和叙事草稿目前均为 v0.1 讨论版本，其中建议参数和候选参与方尚待确认。Libra 研究注明历史资料的版本、来源及适用范围。

白皮书原稿标注“对外草稿 · 待律师审核”；其中运行状态、性能数据、32 张种子卡和路线图仍保留原稿口径。最新方案中的建议参数与原稿历史数据应分别阅读，待确认后再形成下一版白皮书。
